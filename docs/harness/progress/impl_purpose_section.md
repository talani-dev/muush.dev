## Findings for `docs/harness/findings.md`, and doc contradictions

(1) Vue propagates a parent's scope id through **two** levels of single-root pass-through (`PurposeCard` → `GlassPanel` → `<article>`), so `.node > .card` in a `<style scoped>` matches with no `:deep()` — probed before relying on it. (2) Vue Test Utils resolves a component wrapper's `element` to the **parent** DOM node when that component's root is itself a component, so `findAllComponents(X).classes()` silently returns the row's classes and every `not.toContain` passes for the wrong reason. (3) CDP `Input.dispatchMouseEvent` *does* drive `:hover`; the earlier failure was dispatching **below the fold**, because `getBoundingClientRect` is viewport-relative — scroll first, then read the rect. (4) `Emulation.setEmulatedMedia` has no `hover`/`pointer` feature; `(hover:none)` needs `setTouchEmulationEnabled` + `mobile:true`, verified with `matchMedia`. (5) Tailwind's minifier rounds token percentages (`13.28125%` → `13.2813%`). (6) `.specify/feature.json` arrived failing `pnpm check` and blocked the gate — fixed with one space pair; and Biome's `useSemanticElements` rejects `<div role="group">`, so the carousel became a named `<section>`, which adds one landmark the desktop composition does not have.

The six contradictions in `spec.md` all stand. Two more: `ui-map.md` § 4's "atenuadas al 50%" is **45%** in the frame, and its "48px de cada lado" is exact only because the frame leaves 10px of *painted* air between cards — which needs a **negative** layout gap (measured −6.44px), not `gap: 0`, since the 0.88 scale already pulls each painted edge 16.44px inward.
